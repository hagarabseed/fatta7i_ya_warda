# fatta7i_ya_warda
Play Dice — Flutter Course, Task Section 2

A small Flutter app that rolls two dice and shows their total.
The goal is to understand the difference between StatelessWidget and StatefulWidget and to see how setState() updates the screen.

## What the App Does
- Total: Shows the sum of the two dice.
- Dice values: Two numbers, each from 1 to 6.
- Roll button: Rolls both dice with random values and updates total.
- Reset button: Sets both dice back to 1 (total = 2).
- Happy/Sad Asset: Shows happy image if total >= 10, sad image otherwise.

## Learning Objectives
1. Build a basic app with MaterialApp, Scaffold and AppBar.
2. Create a dark theme with ColorScheme.fromSeed() and read color tokens.
3. Arrange widgets with Column, Row, Center, SizedBox and Expanded.
4. Handle button presses with ElevatedButton and onPressed.
5. Generate random numbers with Random() from dart:math.
6. Explain why a StatelessWidget cannot update the UI and how a StatefulWidget solves this.
7. Use setState() to change data and rebuild the screen.
